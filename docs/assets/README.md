# Brand assets

The original folded-note mark and lowercase wordmark are provided as SVGs, with no external fonts, scripts, or image dependencies. The fold is a small visual accent; the compact mark works on its own.

- `logo.svg`: horizontal wordmark with a light/dark text treatment.
- `mark.svg`: square icon on a deep ink field with a periwinkle fold.

Use the SVG files directly for crisp rendering at any size. These original assets are covered by the project's Apache-2.0 license. Supply an accessible name in the embedding context or use an empty alt attribute when adjacent text repeats the name.
