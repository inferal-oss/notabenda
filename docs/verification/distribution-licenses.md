# Distribution license review

## 23 October 2026

The npm advisory query for the committed workspace lockfile reported zero listed vulnerabilities. This is a dated database result; it does not establish that the dependencies or application are vulnerability-free. The [Worker toolchain review](toolchain-dependencies.md) records the earlier Undici findings and correction.

The three source-built package archives were inspected separately from the website output. Each contains the Notabenda license choice and the complete Apache 2.0 and MIT texts. The core archive also contains the Ajv, YAML, smol-toml, saxes and xmlchars notices, the imported catalog attribution/license, and the EU artwork and California icon notices. Their bytes match the maintained build inputs. The [upstream saxes 6.0.0 license](https://raw.githubusercontent.com/lddubeau/saxes/v6.0.0/LICENSE), including its inherited notices, matches the maintained copy; the upstream npm package omits that file.

Core and Cloudflare declare no ordinary runtime dependencies. Authoring declares its matching core package plus 13 external dependencies, installed separately rather than copied into its archive. Tracing required dependencies and required peers through the locked tree, excluding optional peers, found 154 external package instances: 149 declare MIT, two BSD-3-Clause, two ISC and one BSD-2-Clause. These are metadata declarations, not an independent review of every file or transitive license. The separate Astro example and build-tool dependencies must not be mistaken for this authoring closure.

## Website and reusable example output

The review found that the website copied YAML and generated Ajv code and bundled React/Astro examples without supplying all their complete license texts in the public output. Short retained React copyright comments did not provide the full license text.

`examples/static/licenses.mjs` now copies complete upstream texts for YAML, Ajv, React, React DOM, Scheduler and Astro, plus Notabenda's own license texts. A versioned index at `/assets/THIRD-PARTY-NOTICES.txt` links those files and the existing catalog notices. It accompanies the reusable static example build as well as this website; the website footer links it.

Selected esbuild input inventories identified React, React DOM and Scheduler in the React browser examples. An Astro build inspection identified Astro as the only third-party package in its emitted navigation client; its server-only modules were considered separately. The optional configuration codec contains YAML, and the configuration validator is generated by Ajv. This inventory covers the reviewed output and must be revisited when browser dependencies change.

The site regression fails against the previous output because the notice index is absent. It compares every newly distributed text with its upstream or maintained source bytes, checks the recorded versions and catalog notices, and checks the footer link. Existing official-artwork notices remain separate; the dual code license does not relicense imported data or agency artwork.

This review does not certify legal compatibility, third-party ownership, every build dependency, or arbitrary adopter distributions. Broader security and content review remains a release task.
