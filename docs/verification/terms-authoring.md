# Terms agreement authoring verification

The shared settings validator checks complete, bounded plain data and all configured scopes before selecting one. Tests reject duplicate IDs, unknown fields, draft production entries, unresolved wording, control characters and accessors. Omitted settings preserve legacy public projection and offer format. Host-authored scopes remain available; configured scope wording cannot be overridden through the legacy factory.

Baseline-bound add/update/remove batches require complete wording, fresh current revisions and explicit removal. They return detached draft settings, preserve unrelated site/consent facts and reset document review. Browser tests cover blank fields, Enter behavior, failed/stale host adoption, prepared export invalidation, unfinished session drafts, reset removal acknowledgement and inert retained controls. CLI tests cover ordinary bounded files, symlink rejection, final confirmation baseline rechecks, scoped wizard output and private file permissions.

Build tests compare emitted scope files with offers generated from the final catalog-attached artifact. Retained configured offers reconstruct their exact identity. The standalone Cloudflare validator uses the same portable policy and rejects independently rehashed archives with malformed, duplicate or draft declarations and mismatched configured copy. Tests preserve independent scopes, separate activation and acknowledged retries after retirement. Wording changes preserve actual remembered cookie grants and compiled cookie inventory.

These checks do not establish legal wording, applicability, historical revision uniqueness, publication, actual host authorization or delivery behavior. Non-English acceptance still requires the complete matching localization.terms dictionary. Native layout checks supplement the DOM and package tests; they do not certify devices or screen readers.
