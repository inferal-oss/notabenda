# Compiled authored release preview

Package checks use actual Markdown and MDX builds with component-only HTML, private source comments, source/body/component references and a supporting privacy-request page. The helper does not evaluate components again. Inputs are snapshotted before asynchronous work; private build fields and option/input accessors are not executed. Altered, extra, malformed or denied preview-mode data fails.

Python's independent ZIP reader verifies CRCs, fixed timestamps, ordinary entry attributes and every exported file byte against the compiler output. A local HTTP fixture serves the exported files and passes the existing four-resource publication checker. Original bytes stay separate from the reading projection, including a self-consistent hostile-HTML fixture whose scripts, forms, URLs, frames and foreign content do not survive in the reader. Offline tarball/TypeScript consumption verifies the optional entry and packaged reader styles.

Website checks cover the actual example, static access without a demo database, narrow frame CSP, public download bytes, no private-source export and semantic structure. Native-browser checks cover styled document frames, switching documents, disclosure controls and mobile layout. These checks do not verify arbitrary host CSS, all platforms, original-content trust, deployment acceptance or legal review.
